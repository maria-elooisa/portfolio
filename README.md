# Portfólio de Maria Santos

Este é o repositório do portfólio de Maria Santos, desenvolvido com Node.js e Express. O portfólio inclui seções para projetos, habilidades e contato, com um design responsivo e moderno.

## Funcionalidades

- **Home**: Apresentação com nome e imagem de capa.
- **Projetos**: Exibição de projetos com navegação entre eles.
- **Habilidades**: Cards interativos mostrando habilidades e descrições.
- **Contato**: Informações de contato com ícones de LinkedIn e email.

## Tecnologias Utilizadas

- **Node.js**: Ambiente de execução JavaScript.
- **Express**: Framework web para Node.js.
- **HTML5**: Estrutura das páginas.
- **CSS3**: Estilização das páginas.
- **JavaScript**: Funcionalidades interativas.

## Instalação

1. **Clone o repositório**:
    ```bash
    git clone https://github.com/seu-usuario/meu-portfolio.git
    ```

2. **Navegue até a pasta do projeto**:
    ```bash
    cd meu-portfolio
    ```

3. **Instale as dependências**:
    ```bash
    npm install
    ```

4. **Execute o projeto**:
    ```bash
    node app.js
    ```

5. **Abra o navegador e acesse**:
    ```
    http://localhost:3000
    ```

## Estrutura do Código

- **app.js**: Configuração do servidor Express.
- **public/**: Arquivos estáticos (CSS, imagens, JavaScript).
- **index.html**: Página principal do portfólio.
